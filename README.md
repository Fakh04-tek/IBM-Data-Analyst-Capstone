# IBM-Data-Analyst-Capstone
Data analysis of programming languages, databases, technology trends, and demographics using IBM Cognos Analytics.

## About This Project

This IBM Data Analyst Capstone project examines current and future technology trends using developer survey data.

The project includes data collection, data cleaning, data wrangling, exploratory data analysis, and interactive dashboard development using IBM Cognos Analytics.

### Key Findings

- JavaScript, HTML/CSS, and SQL are widely used technologies.

- Python, SQL, and TypeScript show strong future interest.

- PostgreSQL leads current and future database preferences.

- AWS is a leading cloud platform.

- Demographic analysis examines respondents by age, education, and country.

### Skills Demonstrated

- Data Collection and Web Scraping

- Data Cleaning and Data Wrangling

- Exploratory Data Analysis

- Data Visualization

- IBM Cognos Analytics

- Dashboard Development

- Interpretation and Communication of Analytical Findings

### Project Deliverable

A 20-slide presentation summarizing the methodology, visualizations, key findings, and conclusions.
